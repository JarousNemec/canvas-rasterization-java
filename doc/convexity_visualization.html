GeometryUtil.isPolygonConvex · ClipTool

Konvexita clip polygonu

Kontrola konvexity chytí konkávní vrchol, hvězdu i motýlka. Propustí ale dva zvláštní případy: hranu, která se po stejné přímce vrátí zpátky, a dva stejné body za sebou. Oba jdou v ClipTool vyrobit obyčejným tažením myši.

Jak se rozhoduje

Tři pravidla aktuální implementace

1. Stejné znaménko otoček

Pro každou trojici prev, curr, next se spočítá pointSide. Všechny nenulové výsledky musí mít stejné znaménko.

2. Součet úhlů ≤ 540°

Konvexní polygon se otočí jednou dokola (360°). Hvězda se otočí dvakrát (720°), proto ji pravidlo 1 samo nechytí.

3. Kolineární trojice se přeskočí

Při pointSide == 0 následuje continue. To je správně pro bod ležící na hraně, ale přeskočí se i otočka o 180° a hrana nulové délky.

Případy

Co kontrola pustí a co ne

Modrá plocha je průnik vnitřních polorovin všech hran. Přesně tuhle oblast použije Sutherland–Hodgman jako ořezovou. U konvexního polygonu je to polygon sám.

otočka se stejným znaménkem problém (jiné znaménko, otočka o 180°, nulová hrana) bod na hraně, přeskočen správně oblast pro Sutherland–Hodgman

Kolineární trojici rozlišit podle skalárního součinu

// GeometryUtil.isPolygonConvex, uvnitř cyklu
long result = pointSide(prev, curr, next);

if (result == 0) {
    //same direction = ok, going back or zero length edge = not convex
    long dot = (long) (curr.getX() - prev.getX()) * (next.getX() - curr.getX())
             + (long) (curr.getY() - prev.getY()) * (next.getY() - curr.getY());
    if (dot <= 0)
        return false;
    continue;
}
  • dot > 0: obě hrany jdou stejným směrem, bod jen leží na hraně. Přeskočí se jako dosud, takže body přidané v ClipTool kliknutím na hranu pořád projdou.
  • dot < 0: hrana se vrací po stejné přímce (otočka o 180°). Polygon není konvexní.
  • dot = 0: jedna z hran má nulovou délku, tedy dva stejné body za sebou. Hrana nemá směr, takže pro ořezávání nedává smysl.
